# Projeto Web Design

Uma página demonstrativa para apresentar um curso de Web Design e Desenvolvimento. O layout utiliza uma fotografia como fundo, detalhes em laranja e uma área visual de login.

## Elementos da página

- Menu de navegação e campo de busca.
- Apresentação do curso e botão “Join Us”.
- Campos de e-mail e senha, link de cadastro e ícones de redes sociais.
- Efeitos visuais ao passar o mouse sobre links e botões.

> **Importante:** o projeto é uma demonstração visual estática. A busca, o login, o cadastro, a navegação e os botões de redes sociais não estão implementados. Os links apontam para `#`.

## Tecnologias

- HTML5
- CSS3
- [Ionicons](https://ionic.io/ionicons) para os ícones, carregados por CDN (é necessária conexão com a internet).

## Como executar

Organize os arquivos conforme a estrutura abaixo. Se necessário, renomeie `index-3.html` para `index.html` e `style-3.css` para `style.css`, mantendo o nome da imagem exatamente como está:

```text
projeto-web-design/
├── index.html
├── css/
│   └── style.css
└── img/
    └── Captura de tela 2024-04-12 171430.png
```

Abra `index.html` em um navegador. Não é necessário instalar dependências. O layout atual usa dimensões fixas e pode não se adaptar bem a telas pequenas.
