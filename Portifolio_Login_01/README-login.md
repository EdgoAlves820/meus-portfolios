# Tela de Login

Uma página de login desenvolvida com HTML e CSS, com uma imagem de Sergipe ao fundo e um formulário com efeito de vidro fosco.

## Funcionalidades da interface

- Campos obrigatórios para usuário e senha.
- Opção visual para lembrar o usuário.
- Links de recuperação de senha e cadastro.
- Ícones nos campos e efeitos ao passar o mouse.

> **Importante:** este projeto é uma interface visual. Não há autenticação, armazenamento de dados nem implementação de recuperação de senha ou cadastro. Os links são apenas demonstrativos.

## Tecnologias

- HTML5
- CSS3
- [Boxicons](https://boxicons.com/) para os ícones
- [Google Fonts](https://fonts.google.com/) para a fonte Poppins

Os ícones e a fonte são carregados da internet; sem conexão, podem não aparecer como esperado.

## Como executar

Organize os arquivos conforme a estrutura abaixo. Se necessário, renomeie os anexos `index-2.html` para `index.html` e `style-2.css` para `style.css`:

```text
projeto-login/
├── index.html
├── css/
│   └── style.css
└── img/
    └── Sergipe1.jpg
```

Depois, abra `index.html` em um navegador. Não é necessário instalar dependências para visualizar a página.
